# TO DO

A polished, offline-first Android to-do app built around simple daily planning.

The app keeps tasks organized by day, remembers them locally, supports important stars, and uses small motion details to make the UI feel alive.

## Language

TO DO supports **English and Persian**. When Persian is selected, the interface becomes fully RTL with Persian week days, Persian month names, Solar Hijri dates, Persian numerals, and Persian UI text. The original TO DO logo/branding remains unchanged.
